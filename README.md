# Калькулятор пиров

Веб-калькулятор: выбираете блюда и число персон, получаете количества продуктов, список закупки и ингредиенты для готовки. Количества в граммах и миллилитрах.

**Версия:** v0.1 (три экрана: «Блюда», «Покупки», «Готовка»).

**Данные:** 20 блюд вегетарианской индийской кухни; плотности ингредиентов — из USDA FoodData Central, часть значений приблизительные (отмечены «≈»).

**Не сделано в v0.1:** этапы готовки (заглушка), сохранение выбора при обновлении страницы.

Пет-проект, кейс для портфолио. Один файл `index.html`, без библиотек.
